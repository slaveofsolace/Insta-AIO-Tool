# 3.1.7 acceptance

Current Instagram profile counters use hash links in a profile header whose heading names the exact account. Version 3.1.6 required list-path links, so those counters were ignored and the profile-count request was still sent. The fixture has been corrected to reproduce the hash-link markup.

The test matrix contains 393 tests plus the existing extension/userscript, Chrome pairing, 45-state overlay, 11-state PWA, and desktop package checks. Unscoped hash links and a different profile heading cannot supply authoritative totals.

An authenticated comparison with the exact branch userscript must finish before this patch is promoted. No live account mutations are part of this acceptance. Fixture evidence alone is insufficient.
