# 3.1.5 acceptance

Mutual Checker separates captured rows from a complete comparison. Neither interface displays or exports non-mutual results when either list is incomplete.

- 378 tests cover cursor pagination, recycled DOM windows, delayed loading, scroller replacement, missing totals, explicit limited responses, raw-capture preservation, and comparison/export gates.
- The recycled-list fixture exposes only seven reusable rows across 63 accounts, including a mid-list starting position. A separate 27-of-2,104 case must remain incomplete. The API fixture traverses 2,104 accounts in 43 pages without restarting either list.
- Chromium acceptance checks both interfaces: partial data exposes no comparison or comparison download; complete data retains inline browsing, search, and text/JSON downloads. Raw captures remain available.
- Release requires green CI on the exact main commit: 45 overlay states, 11 PWA states, Chrome pairing, Windows/macOS package lifecycle checks, archive inspection, and checksums.
- Reviewed layout baselines retain their original capture provenance. No screenshot tolerance is widened.

No authenticated Instagram check or account mutation was performed for this patch. Synthetic fixtures establish the capture and comparison rules, not a guarantee that Instagram will return every account. Firefox/Tampermonkey live behavior and human screen-reader acceptance remain unverified. Windows is unsigned; macOS packages are ad-hoc signed and not notarized.
