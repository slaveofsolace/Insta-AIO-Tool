# 3.1.12 acceptance

This patch keeps partial Mutual Checker results available while adding guidance for viewer-age filtering. Partial captures also supply Follow / Unfollow review targets, with their uncertainty shown in the existing review and confirmation. Pagination, cooldowns, storage schemas, permissions, and per-profile execution checks are unchanged.

## Checks

- Assembly, 414/414 tests, repository hygiene, dependency verification, generated-userscript parity, and extension/web archive checks passed locally.
- Production extension and userscript fixtures passed, including partial comparisons, downloads, no-click guards, accessibility, responsive layouts, and true 200% zoom.
- Focused tests verify that age guidance appears only for verified partial captures, never complete or older unverified data.
- Both delivery surfaces pass partial Follow and Unfollow target review, uncertainty in the existing confirmation, and cancellation with zero profile-action clicks. Tests retain account provenance checks and invalidate a review when its completeness changes.
- The two intended partial-result overlay changes and three version-label changes were reviewed before accepting the new baseline. The other 40 states retained the prior rendered pixels. A non-updating check passed all 45 states; the baseline manifest SHA-256 is `47925acd016dfdcd08c21bb44e7058a251f31c431b8987a54c84430f2d85179c`.
- Release promotion still requires the exact main revision's complete CI matrix, visual checks, Windows/macOS package lifecycle checks, archive checks, and checksums.

## Limits

The cited Instaloader report demonstrates that a missing birthday on the signed-in viewer can hide age-restricted accounts, but also records missing accounts after age verification. The toolbox cannot inspect the viewer's birthday or identify records Instagram did not return. It presents age filtering as a possible cause. Partial differences can be reviewed for actions, but are not proof that an account is a non-mutual.

No live Instagram requests or account mutations are part of this patch's checks. Automated fixtures do not prove full-list availability, Firefox live behavior, or human screen-reader acceptance. Windows is unsigned; macOS packages are ad-hoc signed and not notarized.
