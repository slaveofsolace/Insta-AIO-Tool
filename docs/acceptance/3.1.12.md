# 3.1.12 acceptance

This patch keeps partial Mutual Checker results available while adding a specific recovery path for viewer-age filtering. The pagination driver, cooldowns, storage schemas, permissions, and action engines are unchanged.

## Checks

- Assembly, 414/414 tests, repository hygiene, dependency verification, generated-userscript parity, and extension/web archive checks passed locally.
- Production extension and userscript fixtures passed, including partial comparisons, downloads, no-click guards, accessibility, responsive layouts, and true 200% zoom.
- Focused tests verify that age guidance appears only for verified partial captures, never complete or older unverified data.
- The two intended partial-result overlay changes were reviewed before accepting the new baseline. The other 43 states retained the prior rendered pixels. A non-updating check passed all 45 states; the baseline manifest SHA-256 is `47925acd016dfdcd08c21bb44e7058a251f31c431b8987a54c84430f2d85179c`.
- Release promotion still requires the exact main revision's complete CI matrix, visual checks, Windows/macOS package lifecycle checks, archive checks, and checksums.

## Limits

The cited Instaloader report demonstrates that a missing birthday on the signed-in viewer can hide age-restricted accounts, but also records missing accounts after age verification. The toolbox cannot inspect the viewer's birthday or identify records Instagram did not return. It therefore presents age filtering as a possible cause and keeps partial differences non-actionable.

No live Instagram requests or account mutations are part of this patch's checks. Automated fixtures do not prove full-list availability, Firefox live behavior, or human screen-reader acceptance. Windows is unsigned; macOS packages are ad-hoc signed and not notarized.
