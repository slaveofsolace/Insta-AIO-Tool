# 3.1.9 acceptance

The single-pass background workflow is based on 3.1.3. Later DM conversation-change protection, incomplete-list guards, storage compatibility, and patched dependencies remain in place. Experimental alternate-source and automatic dialog workflows are not included.

## Checks

- 400/400 tests passed locally, with assembly, generated-userscript parity, extension build, and web archive verification.
- 45/45 overlay states and 11/11 PWA states passed without changing screenshots or tolerances. Original screenshot capture provenance is retained.
- Chrome extension/PWA pairing passed. Dependency audit reported no known vulnerabilities after updating xmldom and js-yaml build dependencies.
- Deterministic request tests cover Retry-After seconds and dates, missing or malformed headers, backoff, same-page retries, Stop, navigation, deadline expiry, and retry exhaustion.
- Chromium fixtures exercise the production buttons, fetch transport, visible countdown, retry, and Stop in both extension and generated userscript. These fixtures serve synthetic data only.
- Release promotion requires the exact main revision's full CI matrix, visual checks, package inspections, and checksums.

## Compatibility limits

The original 3.1.3 build also encountered HTTP 429 before reading either relationship list. The response supplied no Retry-After. Neither the restriction's duration nor whether it applies to an account, session, endpoint, or IP is established.

Cooldowns reduce repeated requests; they do not recover omitted accounts or bypass restrictions. Current authenticated comparison success remains unverified. Human screen-reader acceptance and Firefox live behavior remain unverified. No live account mutations are part of this patch's checks.

Windows is unsigned. macOS packages are ad-hoc signed and not notarized.
