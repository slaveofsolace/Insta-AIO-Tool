# 3.1.8 acceptance

Instagram's native list requests carry live web-session headers. A request without those headers can return the full Instagram HTML page with HTTP 200 instead of relationship JSON. The native list also recycles rendered rows, so one scroll sweep can miss accounts even after reaching the bottom.

Version 3.1.8 keeps the guided Followers, close, Following, close sequence and uses Instagram's native list requests throughout. If a sweep ends short, the checker revisits that dialog with tighter overlapping scroll steps while retaining unique observed usernames. It accepts a list only when the unique count equals the unchanged exact profile total. Changed totals, conflicts, challenges, rate limits, and incomplete lists remain partial.

Fresh verification passes assembly, generated-userscript parity, repository hygiene, all 482 tests, extension and userscript Chromium acceptance, all 45 reviewed Windows overlay states, and all 11 reviewed Windows PWA states. Screenshot tolerances are unchanged.

The exact-count authenticated run of the 3.1.8 userscript is still pending. No Follow, Unfollow, or Unsend mutation is part of this acceptance.
