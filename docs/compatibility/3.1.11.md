# 3.1.11 compatibility

Open a profile and choose **Check Followers + Following**. Neither list needs to be opened or scrolled. Available results can be viewed, searched, and downloaded even when a list is partial.

Partial comparisons show “Not found in followers” and “Not found in following” with a warning. Those differences are not confirmed non-mutuals. The readable report and schema-1 JSON include the same uncertainty; JSON adds `partial`, `labels`, and `warning` without removing existing fields. See [partial results](../MUTUAL_CHECKER_PARTIAL_RESULTS.md).

Existing exact-profile counter detection, single cursor traversal, cooldowns, permissions, migrations, and action confirmations are unchanged. Incomplete or unverified captures cannot automatically seed comparison-based Follow / Unfollow runs.

Authenticated full-list availability, Firefox live behavior, and human screen-reader acceptance remain separate checks. This patch makes no claim to identify deactivated accounts or bypass Instagram restrictions.
