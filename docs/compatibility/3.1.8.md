# 3.1.8 compatibility

Open the matching Instagram profile and select **Check Followers + Following**. Both lists are read in the background. Keep the profile open until the check finishes; no list dialogs need to be opened.

The reader resolves the exact account and follows one bounded cursor chain per list. A saved comparison still requires complete lists with unchanged totals and no contradictory relationship evidence. Errors never trigger another route automatically.

## Verified follow-backs

On the logged-in account's own profile, Instagram may supply explicit follow-back status for each returned Following account. The checker uses those strict boolean values to show verified mutuals and accounts that do not follow back, without treating missing Followers rows as evidence. Unknown, malformed, or conflicting status cannot classify an account.

List coverage is separate from individual status. Each group is labeled partial unless its underlying list is complete. A profile counter can disagree in either direction with the returned accounts. Matching counts also cannot override an explicitly contradictory relationship.

Known followers you do not follow back require a complete Following list or their own explicit relationship flags. Missing names in an incomplete Following list are not classified by subtraction.

These reviews last until reload and do not overwrite saved comparisons or become Follow / Unfollow targets. **Download comparison** exports a readable review; Advanced JSON uses the distinct `insta-toolbox-relationship-review` kind. Existing comparison, storage, and queue formats are unchanged.

## Optional visible scan

**Capture lists and export → Scan Instagram lists** opens Followers, reads its virtualized rows, closes it, and repeats with Following. Leave the tab untouched during this route. If Instagram recycles rows before every username is observed, the same check revisits the native dialog with tighter overlapping scroll steps. Both lists must equal the unchanged profile totals before this route can save a comparison.

The checker waits up to ten seconds for initial rows or a scroll container. It checks all visible pagination indicators and stops a loader that remains visible for six seconds. A timeout does not replace the saved comparison or open the next list. Stop and Instagram restriction signals remain active during these waits.

Suggested profiles are excluded. If Instagram shows an empty list despite a positive profile total, the check stops and preserves the saved comparison. A native request redirecting to the homepage was observed during authenticated testing; scrolling cannot recover list data from that response. Full authenticated compatibility remains unverified.

Background requests use 50-account pages. Changed totals, missing cursors, or read limits leave coverage incomplete. Profile changes, restrictions, and unreadable responses stop without replacing saved data.

Full authenticated comparison remains unverified. If neither route provides complete lists, import an Instagram information export in the web or desktop app. An account missing from an incomplete list is unknown, not proof of a non-mutual relationship. The displayed profile total alone cannot identify accounts that Instagram has not supplied.

Storage, permissions, action engines, and existing export schemas are unchanged. Windows remains unsigned; macOS packages are ad-hoc signed and not notarized.
