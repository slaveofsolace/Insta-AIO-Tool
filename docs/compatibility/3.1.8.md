# 3.1.8 compatibility

Open the matching Instagram profile and select **Check Followers + Following**. Leave that tab open and untouched while the checker opens Followers, reads the virtualized list, closes it, and repeats with Following.

If Instagram recycles rows before every username is observed, the same check revisits the native dialog with tighter overlapping scroll steps. Both lists must equal the unchanged profile totals before the comparison or its downloads become available.

The checker waits up to ten seconds for initial rows or a scroll container. It checks all visible pagination indicators and stops a loader that remains visible for six seconds. A timeout does not replace the saved comparison or open the next list. Stop and Instagram restriction signals remain active during these waits.

Suggested profiles are excluded. If Instagram shows an empty list despite a positive profile total, the check stops and preserves the saved comparison. A native request redirecting to the homepage was observed during authenticated testing; scrolling cannot recover list data from that response. Full authenticated compatibility remains unverified.

**Capture lists and export → Check in background** offers a separate read-only route without opening either dialog. It resolves the exact account, follows one cursor chain per list with 50-account page requests, and saves only when both unique lists match unchanged profile totals. It stops on changed server totals, missing cursors, profile changes, restrictions, or unreadable responses. It never switches routes automatically after an error.

The installed background reader completed both cursor chains during authenticated testing. Following matched its declared total, but Followers ended below its unchanged total. Network observation confirmed the reader retained every returned account, including the first page, with no duplicate or invalid rows. Instagram explicitly reported no next page. The cause of the missing follower records is unknown; this is not proof of a rate limit or deactivated accounts. See the [acceptance record](../acceptance/3.1.8.md).

Full authenticated comparison remains unverified. If neither route provides complete lists, import an Instagram information export in the web or desktop app. An account missing from an incomplete list is unknown, not proof of a non-mutual relationship. The displayed profile total alone cannot identify accounts that Instagram has not supplied.

**Stop**, page interaction, profile or dialog changes, ambiguous controls, challenges, rate limits, sign-in failures, changed totals, and incomplete results stop safely. The previous complete comparison is preserved, and partial captured rows remain under Advanced.

Storage, permissions, action engines, and export schemas are unchanged. Windows remains unsigned; macOS packages are ad-hoc signed and not notarized.
