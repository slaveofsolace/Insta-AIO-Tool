# 3.1.10 compatibility

Open a profile and choose **Check Followers + Following**. Neither list needs to be opened or scrolled.

Exact counts can come from full profile-list links or `#` links inside the uniquely identified current profile header. Rounded counts without an exact title, hidden or unrelated links, ambiguous headers, and conflicting totals are not trusted. Counts are checked again after traversal; changed totals cannot produce a complete comparison.

This removes unnecessary profile-metadata requests when exact totals are already displayed. It does not bypass Instagram restrictions or guarantee that relationship endpoints return every account. Rate-limit cooldowns, partial-list handling, storage, permissions, and action engines are unchanged. See [cooldowns](../MUTUAL_CHECKER_COOLDOWNS.md).

Authenticated full-list success, Firefox live behavior, and human screen-reader acceptance remain unverified for this build. No live account mutations are part of this patch's checks.
