# 3.1.4 compatibility

The extension and Tampermonkey bundle share the same DM cancellation guard. It supports browsers without the Navigation API using DOM observation and a 200 ms check while a conversation operation is active.

Keep the conversation being cleared open in its tab. Use another Instagram tab for other conversations. Switching the active conversation cancels the run; returning requires a fresh confirmation. A deletion already submitted to Instagram cannot be recalled.

Automated Chromium fixtures cover the shared runner and both interfaces. Firefox/Tampermonkey authenticated acceptance remains unverified. Existing 3.x storage and pairing contracts are unchanged.
