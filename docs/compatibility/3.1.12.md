# 3.1.12 compatibility

Open a profile and choose **Check Followers + Following**. Neither list needs to be opened or scrolled. Available results can be viewed, searched, and downloaded even when Instagram returns a partial list.

For a verified partial result, the panel explains viewer-age filtering as one known cause and links to the signed-in account's Accounts Center. The readable report and schema-1 JSON carry the same guidance. This is not a diagnosis: the Instaloader report that established the age-filter behavior also includes a case that remained incomplete after age verification.

Existing exact-profile counter detection, single cursor traversal, cooldowns, permissions, migrations, and action confirmations are unchanged. Incomplete or unverified captures cannot automatically seed comparison-based Follow / Unfollow runs.

Authenticated full-list availability, Firefox live behavior, and human screen-reader acceptance remain separate checks. This patch does not bypass Instagram restrictions or identify accounts Instagram omitted.
