# 3.1.6 compatibility

Open the profile, then select **Check Followers + Following** in Mutual Checker. Keep the profile open until it finishes. Followers and Following are read in the background; neither dialog needs to be opened or scrolled.

Exact totals come from links belonging to the open profile, including exact numeric tooltips when a displayed count is abbreviated. If exact totals are unavailable, the existing profile-count endpoint remains available. When the check uses the open profile, it reads the same counters again at completion without another request. Changed totals or missing context cannot produce a complete comparison.

Instagram can return HTML for a rate limit or sign-in requirement. The checker now reports those states correctly and stops. It does not retry a rate limit or switch to another data source after one. Wait before starting another check.

Each relationship list still uses one cursor traversal. A partial, limited, or unfinished list cannot produce inferred non-mutuals or comparison downloads. Partial raw captures remain available under **Capture lists and export**. Optional manual scans retain recycled rows, but cannot force Instagram to expose accounts the server withholds. Count agreement is not an atomic snapshot guarantee if memberships change during the check.

Storage schemas, pairing, exports, queues, and ledgers are unchanged. No permissions or endpoints are added.
